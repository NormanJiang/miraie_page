# Personal Digital Garden

第一次了解项目？先阅读 [网站结构导览](网站结构导览.md)，包含布局图、页面关系、源码职责和常见修改入口。

站点名称与作者名称为 `miraie`。右上角“文/A”菜单可切换中文、英文、日本語，首次打开时按浏览器的首选语言自动选择：中文（zh，包括地区变体）或日语（ja）使用对应语言，其他语言及无法检测时默认英文。手动切换后在本机保存选择，后续访问优先使用已保存的语言。自动检测结果不写入偏好，未手动选择时可随系统语言变化。导航、栏目、搜索、主题控件、页脚等固定界面已翻译；文章和项目正文保留原文。

翻译文案集中在 `src/i18n.js`，语言菜单组件为 `src/LanguageSwitcher.jsx`。新增固定界面文案时，请同时填写中文、英文、日文版本。

右上角全站搜索会索引 `src/data.js` 中的文章（标题、摘要、正文、标签）、项目、主题介绍与个人资料，结果展示标题和两行匹配上下文。新增内容后自动参与搜索；当前没有独立的文件上传后台。搜索组件为 `src/GlobalSearch.jsx`，索引逻辑为 `src/search.js`。

左下邮件按钮及页脚联系按钮会打开联系方式弹窗，展示邮箱和微信 ID，支持复制、Esc 关闭及背景虚化。联系方式保存在 `profile.email` 和 `profile.wechat`；弹窗组件为 `src/ContactDialog.jsx`。

参考 https://www.taniarascia.com/ 的布局与交互，独立实现的个人网站。未使用 Link.txt 的内容。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd G:\MYPAGE
npm install --cache .npm-cache
npm run dev
```

浏览器打开终端显示的地址（默认为 http://127.0.0.1:5173）。

## 构建

```powershell
npm run build
npm run preview
```

`dist/` 是构建好的静态网站，可以上传到静态托管服务。当前未进行在线部署。使用 hash 路由，不需要服务端路由重写。

## 修改内容

- `src/data.js`：姓名、站点名称、个人介绍、邮箱、GitHub、文章、分类和项目。姓名和联系方式已配置；文章及部分项目为示例内容。
- `src/main.jsx`：页面结构、导航、搜索、主题交互。
- `src/styles.css`：配色、排版及响应式布局。
- `index.html`：网页语言、搜索引擎摘要、默认标题。
- `public/favicon.svg`：站点图标。

`profile.email` 和 `profile.github` 填入真实内容后，会显示在关于页面。每篇文章包含唯一 `id`、标题、日期、分类、标签、摘要，以及 `[小节标题, 正文]` 格式的 `body`。

## 已实现

首页、文章归档、关键词搜索、分类筛选、文章详情、主题书架、项目及详情、关于页面、深浅色模式、五种强调色、浏览器本地保存主题偏好、移动端导航、键盘焦点与跳至正文。

默认深色风格。字体通过 Google Fonts 加载 DM Sans 和 JetBrains Mono；离线时自动回退到系统字体。像素小芽为本项目内联 SVG，不依赖远程图片。没有登录、数据采集或后端服务。

## 设计来源

参考站：https://www.taniarascia.com/ 。复现其深色数字花园风格、固定侧栏、内容排版和主题交互；页面文案与像素插图为本项目示例，没有复制原作者的个人身份、文章全文或专属插图。
